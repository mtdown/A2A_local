- 写脚本时踩到的 PowerShell 5.1 坑（重要，下次直接避开）：
  1. `$args` 是自动变量，函数里用 `$args = @{...}` 做 splat 会让 Invoke-RestMethod 静默失败 → 改名。
  2. `[string]$Body = $null` 的参数默认值实际是 `''`，用 `$Body -ne $null` 判断恒为真，
     导致 GET 也被塞 Body → "无法发送具有此谓词类型的内容正文"；改用 `[string]::IsNullOrEmpty`。
  3. 扫描 `~/.workbuddy/logs` 抓口令时 `renderer.log` 被桌面端占用，ReadAllText 会抛异常 → 必须 try/catch 跳过。
